ここに `easy.ogg`、`normal.ogg`、`hard.ogg` を配置してください。

対応形式: Ogg Vorbis、または非圧縮16bit PCM WAV。いずれもモノラルまたはステレオ。
Ogg Opusは未対応です。WAVを使う場合は設定の`audio_file`を対応する`.wav`名に変更してください。
OGGの読み込みにはSoundFileが必要です。導入手順は`docs/bgm-guide.md`を参照してください。
付属設定例には3400 msまでの区間があるため、各曲は4秒以上を推奨します。
実際のリズムに合わせて `config/bgm_settings.json` を調整してください。

楽曲ファイルは同梱していません。
